# Nexus Titan - Versão atualizada

Principais melhorias desta versão:
- Solicitação agora possui motivo, treino, dia e personal responsável.
- Status padrão de solicitação: PENDENTE.
- Evitada a ideia de criar um novo treino para cada solicitação: o personal deve editar treino/dia/exercícios existentes.
- Frontend reorganizado com áreas de Aluno, Personal e Administrador.
- Cadastro com validação básica de e-mail e CPF de 11 números.

## Fluxo recomendado
Aluno -> visualiza treino -> escolhe dia -> abre solicitação -> personal visualiza -> edita treino/exercícios existentes -> marca solicitação como RESOLVIDA.
